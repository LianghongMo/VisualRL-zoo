## 数值证据

- 一步真实动力学：m=1、Δt=0.5、(p,v)=(2,0)、u=−1，得到(1.875,−0.5)。相同推力从v=+1/−1分别到2.375/1.375。
- 单位置Bellman：γ=1、e=2、P=4、R=0.5，u*=−16/9，V(2)=−52/9=−5.777778；u=0、−1、−2的return分别为−20、−8.5、−6。
- 线性特征(1,x)对[-1,0,1]→[−1,0,−1]拟合−2/3；二次特征精确拟合V(x)=−x²。x=2时真值−4，训练点兼容的另一函数可为−14。
- Gaussian单步：u∼N(μ,1)、r=−(u+1)²，μ=0时期望梯度−2、J=−2。baseline方差30+8b+b²；b=0/−2/−4/+2分别30/18/14/50。
- Gaussian KL：均值改0.2，同方差σ=1时0.02；σ=0.1时2。
- GAE：r=[0,1]、V旧=[0.4,0.7,2]、γ=0.9、λ=0.8，真终止A₀=0.446，外部截断1.742；递推不接reset段。
- Surrogate旧q=p=0.5时J=L=0.5；q=0.1,p=0.9时J=1.044,L=1.62；q=0.9,p=0.9时J=1.396,L=0.82。
- PPO ε=0.2，A=2,w=1.5目标2.4；A=−2,w=0.5目标−1.6；A=−2,w=1.5目标−3。
- Jensen：等权1/9，差log(5/3)；调成1/1差0。Q=[0,2]、α=1，softmax第二动作概率0.880797，熵目标达到soft值2.126928。
- 默认LQR：H=6、Δt=0.5、M=diag(1,0.2)、R=0.5、M_H=diag(20,10)、x₀=(2,0)。K₀=(0.9291510326,1.4469941333)，u₀=−1.8583020652，末态(0.0013103942,−0.0580238432)；return=V₀*(x₀)=−x₀ᵀP₀x₀=−12.5001592311。
- 同任务return：不控制−104，只位置反馈−193.1083721202，固定PD−17.7744082101；±1N限幅后实际推力满足界，return低于原无约束最优。
- 固定反馈K=(1,0)/(1,1)谱半径1.060660/0.790569，分别振荡放大/衰减。
- 独立有理数LQR：Δt=1、H=2、M=M_H=I、R=1，K₁=(2/9,2/3)、K₀=(58/149,142/149)，P₀=[[337,152],[152,367]]/149，V₀*(x)=−xᵀP₀x。
- 同p=2,v=0，g=0反馈−1.858302，g=3反馈+0.929151；物理状态不变，任务变化。

## 自动检查

~~~bash
cd web
npm test
npm run build
~~~

66项检查：实验、算法一致性与归档56项，连续机器人课程10项。课程检查覆盖动力学单位、独立LQR解、多初态/目标/时域的reward、return与Bellman恒等式、限幅/扰动/模型误差、Gaussian矩的数值积分、HER/reset边界、全章公式与知识、真实控件及轨迹。

LQR数学项为`Riccati value equals reward return and satisfies Bellman across states, goals, horizons and effort weights`，核对每步reward加后继V、完整return与初始V，以及末端reward。

交互检查用Node/linkedom触发控件，构建用esbuild与KaTeX MathML；浏览器端到端检查另行验收。GitHub检查Python package和离线网页可重建性，构建生成相同的docs/index.html与dist/index.html。
