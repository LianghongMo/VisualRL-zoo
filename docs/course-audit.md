## 数值验收

- γ=0.9：近路回报 0.6561，8步远路回报 4.782969；B 原12步路线回报 3.138105961。
- MC/TD 默认 α=1，完整回合MC与逆序TD都得到 V(S)=0.6561；α=0.5，一次MC得到0.32805，一次逆序TD从零传播得到0.020503125。
- 悬崖算例向下：SARSA连续两次 −20→−60.5→−80.75；Q-learning −20→−15.5→−13.25。终止例两者 −20→−10.5→−5.75。
- Stitching：B后缀 G=7.29；第4轮 V(J)=7.29，第8轮 V(S)=4.782969；已观测子图的贪心策略拼出8步路线。
- 只有A时，无论重复规划多少次，缺失边不会增加；在线采集8步只改数据，重新规划才改变 V。

## 可重复的检查

`cd web && npm test` 检查教学流程、知识点对应正文、可见公式、环境规则以及 Python/JS 算法记录一致性。`npm run build` 生成同一份独立 HTML 到 `docs/` 与 `dist/`。

浏览器检查还覆盖：主线与选读直接链接、前后章节导航和浏览器返回、原生按钮点击、训练完成与中途离页、360/390像素窄屏、短路线完整显示、数学渲染与页面运行错误。浏览器检查的结果应以实际运行记录为准；这份表列的是验收范围。

本次验收结果：28 项自动化测试通过；Firefox 对最终构建产物的桌面原生点击流程通过，后半课程无运行错误；全部8个页面在360/390像素视口下无整页横向溢出、公式渲染错误或知识点回看缺项。500回合训练的本次种子7结果为 SARSA 贪心路线17步、Q-learning 13步；这只记录本次演示，不作为普遍统计结论。训练中离开章节、浏览器返回、数据采集后再规划均通过。

## 实验假设

位置状态充分、确定性且固定的动力学、离散状态动作、奖励定义不变。经验图只在已观察动作上规划。第6章的常数学习率与单个种子实验不构成收敛或统计保证；第7章不是一般离线RL算法。连续状态、随机后果、函数近似和数据外动作需要额外方法。
