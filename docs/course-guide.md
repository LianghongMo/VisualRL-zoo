## 前三章怎样衔接

第1章定义机器人能观察什么、能做什么、环境反馈什么，以及策略怎样产生经验。这里建立任务，不提前推导Bellman或运行求解算法。

第2章用G汇总完整奖励，再用Vπ/Qπ评价一个策略。先执行完整策略A/B/C，说明比较的是长期结果，定义最优控制目标。仍未解决怎样高效评价所有策略。

第3章从终点前一格、前两格和J展示后续未来可复用，总结Bellman关系，再用完整模型进行DP迭代。此时产生下一个自然问题：如果无法查询完整模型，还能怎样学习？第4章用实际回合回答。

赌博机是隔离探索的单步特例。它放在第5章探索小节的补充中，服务于未知动作收益与经验来源的解释；MC控制先在第4章说明简单ε-soft规则。

第9章七小节依次是动作概率、完整策略梯度推导、baseline/Actor–Critic/GAE、surrogate/TRPO、PPO、Jensen/熵、训练实践。先用轨迹概率导出梯度，再用条件期望删掉过去奖励；折扣目标保留外层γᵗ。之后说明方差与均值的区别、优势怎样估计、旧数据目标怎样近似真实目标，最后解释优化约束和实用流程。

| 工具 | 必须能解释的条件与限度 |
|---|---|
| 对数导数与因果性 | 环境和初始分布不依赖θ、策略可微且采样支持合适；过去奖励与当前score的交叉项期望为0 |
| Baseline | 给定状态不依赖当前动作时不改变期望梯度；任意baseline未必降低方差，Vπ未必是最小方差baseline |
| GAE | 真终止不bootstrap；外部截断保留最后状态bootstrap，但递推不跨入reset后的回合 |
| 重要性采样与surrogate | 动作比可精确改写给定旧状态的动作期望；它没有把旧状态占用自动换成新状态占用 |
| TRPO与PPO | 自然梯度步骤使用局部Taylor展开；PPO的min裁剪限制目标收益，不保证真实J下界或硬性概率比/KL上限 |
| Jensen与熵 | log是凹函数；soft价值减去奖励加熵目标恰为温度乘KL；熵正则改变优化目标 |
| 奖励塑形 | F=γΦ(s′)−Φ(s)；有限回合要求终点Φ=0，或显式处理尾部项 |
| 稳定训练技巧 | 分清减少相关性、固定目标、控制梯度和改变任务；用相同预算、多种子与消融评价 |

每个对应小节提供可点击的原始来源。Jensen另给固定环境动力学下的ELBO阅读补充，不把一个不等式当作PPO推导。

## 实验边界

- 地图离散、确定，位置为完整状态；进入充电站终止，后续价值为0。随机后果另列概率。
- 第5章赌博机补充的真实均值只供环境生成奖励，学习规则只读Q/计数。切换估计方式清零，交换真实均值保留估计。
- 第3章用完整模型；第7章仅用观测连接，Dyna 示范采集路线事先指定，正文另解释一般 ε-greedy 采集。
- 第4章指定样本回合。首访/每访默认 α=1显示最新目标；正文另给跨回合均值。重要性采样说明覆盖条件。
- 第5章一步控制用标注旧 Q；展开训练从零运行真实算法。常数步长和单种子不构成统计保证。
- 第6章 n-step 用固定快照，资格迹真正逐步更新；区分离线前向等价与一般在线更新，改 λ 重置痕迹实验。
- 第2章塑形比较原地图两条候选路线，用统一势函数计算奖励；错误终点设置是明确标注的反例。
- 第8章运行线性价值更新和Double DQN目标算例，DQN讲结构与方程；未接入完整DQN网络训练。
- 第9章计算精确二动作梯度/方差、固定价值快照的GAE、两状态surrogate、PPO目标、log Jensen和奖励加熵目标，未接入完整PPO或SAC网络训练。

第10章主要参考 [Benjamin Eysenbach 博士论文](https://ml.cmu.edu/research/phd-dissertation-pdfs/thesis_eysenbach.pdf)（2023，第2–4章、附录B），保留印刷页码与 PDF 定位链接。目标改标实际运行表格 Q-learning；分类为精确 Bayes 算例，SoRB使用精确地图距离与局部能力。神经网络 GCRL 完整训练需另外实现和评估。
